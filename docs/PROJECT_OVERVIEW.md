# Project Overview

**Title:** AI Powered Placement Management System

**Objective:** Centralize student profiles, recruiter requirements, applications and intelligent job recommendations.

**Users:** Placement Officer, Students, Recruiters and Administrator.

**Technology:** HTML/CSS/Bootstrap, Python Flask, SQLite.

**AI Layer:** Explainable weighted matching baseline using CGPA, skills, projects, internships, communication and aptitude.

**Future Enhancement:** Train a supervised ML model using historical placement data and replace the baseline scoring function.
